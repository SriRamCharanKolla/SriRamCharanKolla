## 👋 About Me

I’m a **Software Engineer focused on Cloud & DevOps, Full-Stack Development, and cross-platform Mobile Applications**. My commercial experience is strongest in **Angular, Ionic, TypeScript, REST API integrations, real-time workflows, and offline-first applications**.

At **Kerve Technologies LLP**, I took primary responsibility for the frontend of healthcare administration and onboarding portals. I improved navigation and application performance, implemented **NgRx state management, role-based access, Socket.IO real-time events, Razorpay integrations**, and features supporting appointment and service operations. I also deployed web applications on **AWS EC2 using Linux and Nginx**.

I build across the stack: an **AI appointment-booking prototype** using **Python, FastAPI, Ollama/Llama, and WebSockets**, an **offline-first restaurant POS** using **Ionic, SQLite, and Bluetooth receipt printing**, and other cross-platform application workflows.

Currently, I work independently on **software projects and engineering portfolio builds**, including **Fruitopia (in progress)**. I am also deepening my Cloud/DevOps and DevSecOps capabilities with practical **Terraform, Ansible, Docker, Kubernetes/EKS, Linux, Bash, and CI/CD** projects.

I use AI-assisted development tools to accelerate implementation and debugging, while keeping **testing, security, and engineering validation** part of the workflow.

**My focus:**

- 💻 **Product Engineering:** Web apps, mobile apps, backend integrations, real-time and offline-first features
- ☁️ **Cloud & DevOps:** AWS deployment, Infrastructure as Code, containers, CI/CD, Linux administration
- 🤖 **Applied AI:** LLM-backed application prototypes, local inference, AI-assisted engineering

> **Open to software engineering roles, cloud/DevOps opportunities, and remote freelance projects.**
