## About Me

I am a DevOps Engineer with 3+ years of application engineering experience and hands-on work across infrastructure automation, Linux administration, cloud deployment, and release support.

My current focus is building practical DevOps skills around AWS, Terraform, Ansible, Docker, Kubernetes, Shell scripting, CI/CD workflows, and production-ready deployment practices. I like working close to the runtime: servers, logs, reverse proxies, environment configuration, and the automation that makes releases repeatable.

- Building: AWS infrastructure automation, Roboshop microservices deployment, and 3-tier application deployments
- Practicing: Terraform remote state, Ansible orchestration, Dockerized services, Kubernetes fundamentals, and GitHub Actions
- Comfortable with: Linux, Nginx, EC2, S3, IAM, Route 53, CloudFront, RDS, MongoDB, Redis, RabbitMQ, MySQL
- Background: Angular, Ionic, TypeScript, JavaScript, REST APIs, Socket.IO, Firebase, and mobile/web release workflows
